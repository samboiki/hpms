2. Main Workflow Steps

1. Patient Visit

  • Patient check-in
  • Create/update patient record
  • Verify medical aid
  • Create visit record

2. Clinical Services

  • Record vitals
  • Document diagnosis
  • Select services provided
  • Check medical aid coverage

3. Invoice Generation

  • Calculate service totals
  • Apply medical aid rules
  • Add taxes (15% VAT)
  • Generate invoice number

4. Payment Processing

  • Record payment method
  • Update invoice status
  • Generate receipt
  • Submit medical aid claim

5. Financial Tracking

  • Update practice revenue
  • Track outstanding amounts
  • Generate reports
  • Monitor collections

Invoice Service Functions (invoiceService.ts)

generateInvoiceFromVisit() - Creates invoice from visit and selected services
calculateBilling() - Calculates totals with medical aid coverage
createInvoice() - Persists invoice to database
createInvoiceItems() - Creates individual line items
linkServicesToVisit() - Associates services with visit
updatePaymentStatus() - Updates invoice payment status
recordPayment() - Records payment transactions
submitMedicalAidClaim() - Initiates medical aid claims

Patient Visit Details

Tables Used: patients, visits, medical_aid_details

Components: AddVisitForm, PatientRegistrationForm

Process:

  1. Patient arrives at practice
  2. Receptionist creates/updates patient record
  3. Medical aid details verified if applicable
  4. Visit record created with appointment linkage
  5. Patient sent to doctor/nurse

Service Selection Details

Tables Used: practice_tariffs, medical_aid_coverage, visit_services

Components: ServiceSelector, medical aid coverage indicators

Process:

  1. Doctor/Nurse opens ServiceSelector in visit form
  2. Searches or browses available services
  3. System checks medical aid coverage in real-time
  4. Quantities adjusted as needed
  5. Services linked to visit record

Invoice Generation Details

Tables Used: invoices_enhanced, invoice_items_enhanced

Functions: generateInvoiceFromVisit, calculateBilling

Process:

  1. "Generate Invoice" checkbox checked in visit form
  2. Invoice number auto-generated (INV[YY][MM][00001])
  3. Medical aid portions calculated per service
  4. 15% VAT added for Namibia
  5. Invoice and line items saved to database

Payment Processing Details

Tables Used: payment_records, invoices_enhanced (status update)

Functions: recordPayment, updatePaymentStatus

Process:

  1. Patient makes payment (cash/card/EFT/medical aid)
  2. Payment recorded with transaction reference
  3. Invoice status updated (pending → partial → paid)
  4. Receipt generated for patient
  5. Medical aid claim submitted if applicable

Financial Tracking Details

Tables Used: All billing tables for reporting

Components: Billing dashboard, PremiumBillingModal

Features:

  1. Real-time revenue tracking
  2. Outstanding balance monitoring
  3. Medical aid claim status tracking
  4. Financial reports generation
  5. Patient billing history

4. Key Integration Points

  • Visit-Billing Integration: Billing seamlessly integrated into visit workflow
  • Medical Aid Integration: Real-time coverage checks and automatic calculations
  • Practice Customization: Each practice can have custom tariffs and settings
  • Fallback Mechanisms: System provides 128 dental codes if no tariffs loaded
  • Tax Compliance: Automatic 15% VAT calculation for Namibia
  • Multi-tenant Support: Practice-specific billing configurations
