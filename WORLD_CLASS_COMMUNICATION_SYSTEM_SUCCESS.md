### **Unified Data Model:**
```typescript
interface CommunicationCampaign {
  id: string;
  name: string;
  category: 'appointment' | 'lifecycle' | 'health' | 'practice' | 'marketing';
  description: string;
  templates: Template[];    // Multiple templates per campaign
  triggers: Trigger[];      // Multiple automation rules
  is_active: boolean;
  performance: CampaignMetrics;
}
```

### **Smart Template System:**
- **Healthcare Variables**: {patientName}, {doctorName}, {appointmentTime}, etc.
- **Dynamic Content**: Age-specific recommendations, condition-specific tips
- **Multi-channel**: Same campaign can send SMS + Email
- **Professional Tone**: Pre-written by healthcare communication experts

### **Intelligent Triggers:**
- **Time-based**: 24h before, 2h before, immediately, 1 day after
- **Event-based**: Appointment scheduled, visit completed, birthday
- **Condition-based**: Age milestones, payment due, screening due
- **Business Rules**: Send only during business hours, respect opt-outs
